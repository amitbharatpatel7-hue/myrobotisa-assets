      How to read this
      • Every name and number on this page is made up to show what the dashboard does. Yours shows your own account.
      • The account is in pounds; the indexes are priced in their own currency, so a move in sterling shifts the comparison a little.
      • Stops and 40-week averages use the strategy's own weekly closes and entry prices, not the broker's purchase prices.
      • In the kit, this page sits behind a login only you can pass, and Refresh now uses a read-only broker key that can look but never trade. Not financial advice.
